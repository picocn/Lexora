## 功能验收（需在 `tauri dev` 窗口中人工确认）
### 窗口与菜单结构

- [ ] 顶栏空白区可拖动窗口、双击最大化/还原；品牌按钮与各按钮上按下不会误触发拖拽（点击 logo 必弹菜单）
- [ ] 文件菜单含：新建/打开/最近打开/保存/另存为/预览 Markdown/退出
- [ ] 编辑菜单含：撤销/重做/剪切/复制/粘贴/全选/设置…
- [ ] 帮助菜单可打开：使用说明 / 版本说明 / 许可证… / 关于
- [ ] 许可证…：展示本项目 MIT 全文（© 2026 pico）与主要第三方组件许可证表（CodeMirror/React/Vite/TypeScript/KaTeX/mermaid/markdown-it/highlight.js/Tauri 等），并有指向各依赖包内 LICENSE 的说明
- [ ] 窗口默认只有编辑框（无预览分栏）；状态栏布局按钮与 F5 仍可切换 仅编辑/分屏/仅预览
- [ ] 标签栏：标签多时无滚动条；左侧 ‹ › 循环切换上/下一个标签并自动滚动到可见；＋新建位于顶栏动作区；Ctrl+W 关闭、中键关闭、dirty 圆点与 × 正常
- [ ] 输入并移动光标后停留片刻：光标不跳回原位置（无关重渲染不重建编辑器视图）

### 预览标签页
- [ ] 打开 .md 文件 → 顶栏 `🔎` 预览按钮可用（文件菜单“预览 Markdown”/Ctrl+P 也可用）
- [ ] Markdown 标题自动生成锚点；`## 标题 {#custom-id}`（含中文/全角）自定义锚点生效且标记不外显；重复标题自动去重（-2/-3）；独立成段的 `[TOC]` 渲染为可点击目录
- [ ] 点击目录/文档内锚点：在预览容器内即时、准确地跳到目标标题（不跳到错误位置、无平滑滚动延迟）；http(s) 外链转系统浏览器
- [ ] 点击预览 → 打开只读标签页，标题为 `文件名-预览`，内容为该 md 的渲染结果
- [ ] 回到源编辑标签改动内容 → 切回预览标签看到更新后的渲染（GFM 表格/任务列表生效）
- [ ] 关闭源编辑标签 → 其 `xxx-预览` 标签被一并关闭
- [ ] 非 Markdown 标签不显示预览入口；手动指定语言为 Markdown 后未命名标签也可预览
- [ ] 超大 Markdown（>800 万字符）预览不渲染而是显示“预览已禁用”提示（不 OOM）；编辑不受影响
- [ ] HTML：打开 .html/.htm 时 `🔎` 预览可用（与 Markdown 同入口）；预览为沙箱 iframe 静态渲染（脚本不执行、CSS 隔离）；外链点击转系统浏览器；超大同样禁用提示

### 语法高亮
- [ ] 打开 .py/.rs/.ts/.yaml/.toml/.html 等文件 → 立即按文件类型高亮
- [ ] 状态栏“语言”可手动切换；未知扩展名显示为纯文本可手动指定

### 自动保存语义（核心）
- [ ] 编辑已有文件 → tick 后原文件哈希不变、仅 `autosave/` 出现快照
- [ ] 手动保存（Ctrl+S）→ 原文件更新、该标签快照清除、脏标记消失
- [ ] 新建标签编辑 → 只出快照无磁盘新文件；另存为才写盘
- [ ] **退出**（菜单退出 或 关闭窗口按钮）：**不再弹保存询问**；自动为每个带未保存改动的标签补写一次恢复快照（不写原文件）后直接退出；
      **下次启动自动恢复**这些快照为编辑标签（仍为未保存状态，手动保存才写盘）；启动恢复提示 5 秒后自动消失
- [ ] **关闭单个未保存标签** → 弹 保存 / 不保存并关闭 / 取消；“不保存并关闭”删除该标签快照
- [ ] 崩溃后重启 → 快照自动恢复为标签

### 会话恢复
- [ ] 打开若干文件 → 退出 → `settings/session.json` 记录路径与激活标签
- [ ] 重启 → 上次打开的文件自动重新打开，激活上次激活的标签
- [ ] 会话与快照叠加时不产生重复标签

### 大文件（L1/L2/L3）
- [ ] 打开 >20MB 文件 → 弹「后台打开 / 取消」确认；后台打开不切换当前标签，完成后有提示
- [ ] 启动会话恢复时自动跳过 ≥64MB 文件并提示跳过数量（不阻塞启动）
- [ ] 超大文件（≈55MB+）常驻上限 4 个：再打开更多时，最早的干净超大标签退化为占位（标签仍在）
- [ ] 切换回占位标签 → 显示“正在加载大文件…”后自动重载内容（未保存/小文件标签不受影响）
- [ ] 超大文件标签关闭撤销历史仍可编辑保存

### 文件输入、外部修改与打印（0.4.0）
- [ ] 拖放：把 `.md`/`.txt` 从资源管理器拖到窗口上 → 出现拖放提示浮层，松开后打开为新标签
- [ ] 拖放文件夹或图片/压缩包 → 提示“已忽略 N 个文件夹或非文本文件”，不打开标签
- [ ] 外部打开：资源管理器右键 `.md` →「打开方式」→ Lexora（或 `lexora.exe 文档.md`）→ 应用启动并打开该文件
- [ ] 应用已运行时再次用上述方式打开另一个文件 → 文件出现在**现有窗口**（窗口被置前），任务管理器中没有第二个 Lexora 进程
- [ ] 设置 → 文件 →「注册为默认 .md 打开方式」→ 提示成功；在资源管理器双击 `.md` 由 Lexora 打开（若系统已有用户选择则按提示用「Windows 默认应用设置…」确认）
- [ ] 「取消注册」后 `.md` 不再归 Lexora（`HKCU\Software\Classes\.md` 默认值不再是 `Lexora.md`）
- [ ] 外部修改：用记事本修改一个已打开且**干净**的文件 → 3 秒内弹窗，选「重新加载」内容被磁盘版本替换
- [ ] 外部修改：修改一个**有未保存改动**的标签对应文件 → 弹窗提示可能丢失未保存内容；选「保留当前编辑」后编辑内容不变且不再重复提示（再次改动会再提示）
- [ ] 设置中关闭「检测文件被外部修改」后不再弹窗
- [ ] 打印 Markdown：文件 → 打印…（Ctrl+Shift+P）→ 选择「打印预览版」→ 出现打印窗口（含标题与「打印」按钮），内容为渲染后的排版（表格/代码块/公式/图片），并弹出系统打印对话框
- [ ] 打印 Markdown：选择「打印原始文本」→ 打印窗口内容为 Markdown 源码（等宽字体）
- [ ] 打印其它文本文件（如 `.txt`/`.rs`）→ 不询问，直接进入打印窗口打印原文
- [ ] 打印窗口内容不包含应用顶栏/标签条/状态栏；关闭打印窗口后主窗口正常
