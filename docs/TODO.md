优化需求（已实现，见 0.4.0）
====

1. [x] 支持拖动文件到编辑框打开
   —— 拖拽任意位置显示浮层提示，松开即打开；文件夹与图片/音视频/压缩包等二进制文件忽略并提示（`src/files/dropPaths.ts`）。
2. [x] 文本文件右键选择 lexora.exe 打开，实际不会打开选定文件
   —— 启动参数（`lexora.exe <文件>`）与资源管理器“打开方式”均可打开；并加入单实例转发：应用已运行时把文件交给现有窗口并置前（`commands/launch.rs`）。
3. [x] 设置中增加一个功能，将本应用注册为系统默认 md 文件打开方式
   —— 设置 → 文件 →「注册为默认 .md 打开方式 / 取消注册 / Windows 默认应用设置…」；仅写 `HKCU\Software\Classes`（免管理员），并显示当前 `.md` 归属与 UserChoice 占先提示（`commands/assoc.rs`）。
4. [x] 检测到文件在外部被修改时，弹出提醒是否需要重新加载文件
   —— 每 3 秒比对已打开文件的修改时间/大小（打开与保存时记录基线），变化时询问「重新加载 / 保留当前编辑」；重载会清理过期快照，可在设置中关闭（`src/files/externalChange.ts`）。
5. [x] 支持打印功能：markdown 可选预览版或原始文件，其它文本文件直接打印原始文件
   —— 文件 →「打印…」(Ctrl+Shift+P)；Markdown 预览版走渲染管线（含 KaTeX/Mermaid/内联图片），在独立打印窗口中呈现并调用系统打印对话框（`src/print/`、`commands/print_doc.rs`）。
6. [x] 新建文件另存为 md 格式后，编辑框没有自动进行语法高亮
   —— 另存为成功后若用户未手动指定语言，按新文件名重新识别并即时重配高亮（`App.tsx::saveTabById`）。
