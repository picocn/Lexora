# Lexora 需求文档（Requirements）

- 适用版本：当前实现基线 0.3.9
- 相关文档：`design.zh.md`（设计）、`acceptance.zh.md`（人工验收清单）、`large-file-strategy.zh.md`（大文件性能方案）、`release-notes.md`（逐版本变更）

## 1. 产品概述
Lexora 是一款轻量级 Markdown 多标签桌面编辑器，面向个人写作/笔记场景，定位“开箱即用、便携绿色、不丢数据”：

- 技术栈：Rust + Tauri 2 + WebView2（Windows x64）+ React 18 + CodeMirror 6
- 核心承诺：
  1. **自动保存绝不写原文件** —— 只写恢复快照；
  2. **退出即安全** —— 退出不再询问，自动为未保存内容补写快照；
  3. **可移植** —— 设置/快照默认放 exe 旁，目录不可写时回退系统用户目录；
  4. **大文件可控** —— 超大文件编辑/预览有护栏与驻留上限，避免卡死与 OOM；
  5. **界面统一主题化** —— 顶栏、标签条、下拉菜单、对话框、列表全部跟随当前主题，不出现硬编码配色。

## 2. 目标与非目标
### 目标
- 常用 Markdown（标题/列表/表格/任务列表/代码块/图片/LaTeX/Mermaid/锚点目录）阅读与编辑体验
- 多标签、语法高亮、可中文化的菜单/设置/帮助
- 崩溃与误关不丢未保存内容

### 非目标（本期）
- 不内置云同步/多人协作
- 不做超大型文档的虚拟化渲染（列为远期，见 `large-file-strategy.zh.md` L4）
- 不支持非 UTF-8 原文编辑（UTF-16/32 拒绝打开并提示转存；其他编码尽力显示、只允许另存转 UTF-8）

## 3. 功能需求（实现状态标注：✅ 已实现）

### 3.1 窗口与外壳 ✅
- 无原生标题栏，自绘**单行 36px 顶栏**，从左到右依次为：
  1. 品牌区：应用图标 + “Lexora”，整体是一个按钮，点击展开品牌下拉菜单（原菜单栏已收进该下拉，不再与标签条同排）；
  2. 标签条（内嵌于顶栏中段，可横向伸缩）；
  3. 动作区：`🔎` 预览、`＋` 新建（图标按钮）；
  4. 窗口控制：最小化 / 最大化-还原 / 关闭，宽度与高度铺满顶栏（Edge 风格），悬停样式分明，关闭悬停为红色 `#c42b1c`。
- 最大化/还原图标按真实窗口状态切换（监听窗口 resize 事件与 `isMaximized` 查询），不出现“状态与图标不一致”。
- 移动窗口：仅顶栏的空白拖拽区（品牌菜单/标签/按钮之外的区域）可拖拽；双击该区域最大化/还原。**按钮上按下不会触发拖拽**（修复历史上“点 logo 不弹菜单”的问题）。
- 窗口大小/最大化状态持久化，启动恢复后显示（避免闪烁）。
- 帮助：使用说明 / 版本说明 / 许可证（MIT 全文 + 主要第三方许可表）/ 关于；对话框配色跟随当前主题。

### 3.2 菜单交互 ✅
- 品牌下拉为**纵向一级菜单**（文件 / 编辑 / 帮助），条目悬停展开**右侧二级面板**：
  - 一级之间移入即切换面板；一级到二级之间允许小段“空隙移动”（约 180ms 延迟关闭），鼠标进入面板即取消关闭，避免斜向移动时菜单消失；
  - 二级面板顶部与一级条目对齐（同高起点），不出现“下移一行”；
  - **点击任意菜单项（含二级项）后品牌下拉立即收起**，不残留浮层；
  - 键盘辅助键（如菜单项标注的 Ctrl+O/Ctrl+S/Ctrl+P 等）在菜单文本右侧提示。
- 所有弹出层（品牌下拉、二级面板、子列表、最近打开列表）宽高与配色遵循主题变量。

### 3.3 标签与多文档 ✅
- 编辑标签与只读预览标签（`xxx-预览`）
- 标签条**无滚动条**：左侧 ‹ › 循环切换上/下一个标签并自动滚动到可见；最右「＋」新建（现位于顶栏动作区）
- 关闭：菜单/× /Ctrl+W /中键；关闭未保存单个标签需确认（保存 / 不保存并关闭 / 取消）
- 未保存指示（●）、语言显示
- 最近打开列表：上限 **20** 条（前端写入与后端读取两侧同时裁剪，旧配置超限自动收敛）
- **光标稳定性**：输入并移动光标后，编辑器视图不因无关重渲染被重新建/复位（修复“光标偶尔跳回原位”）

### 3.4 编辑与语法 ✅
- 按扩展名自动语言（md/yml/toml/html/css/js/ts/json/rust/python/java/c/c++/c#/go/sql/sh/ps1/php/rb/xml…），状态栏可手动覆盖
- 撤销/重做（超大文件标签关闭 undo 历史）、剪贴板、全选
- 查找/替换：Ctrl+F 打开面板（查找+替换栏），上一个/下一个/全部替换（执行前确认替换数），区分大小写/正则/整词

### 3.5 自动保存与恢复（核心语义）✅
- 定时（默认 5s，可配置/关闭）把有未保存改动的编辑标签写入**恢复快照**（autosave/），**从不覆盖原文件**
- 手动保存/另存为是写原文件的唯一入口（原子写，防截断；同文件保存保留 UTF-8 BOM）
- 启动：自动恢复遗留快照（提示 5s 自动消失）→ 重开上次会话文件（跳过 ≥64MB 并提示）→ 无标签则新建未命名
- 退出（菜单/关闭按钮）：先存会话，再为所有未保存标签补写最新快照，清理干净标签的过期快照，然后退出——**不弹保存询问**

### 3.6 Markdown / HTML 预览 ✅
- 预览入口：顶栏 `🔎` / 文件菜单/Ctrl+P；Markdown 与 HTML(.html/.htm) 同一入口
- Markdown：实时只读渲染，GFM 表格/删除线/任务列表；LaTeX（KaTeX）；Mermaid；本地图片（含中文/空格路径）经 base64 加载
- **锚点与目录**：
  - 标题自动生成锚点 id（英文化 slug），重复标题自动追加 `-2/-3` 去重；
  - 支持 GitLab 风格自定义锚点 `## 标题 {#custom-id}`：标记在渲染前被剥离，id 取自定义值（标题可含中英文/全角字符，标记允许出现在行尾并容忍尾随空白）；
  - 自定义 id 优先于自动 slug；独立成段的 `[TOC]` 渲染为可点击目录（`<nav class="md-toc">`）；
  - 点击目录/文档内锚点：在预览容器内即时定位（等值滚动，不做平滑动画），匹配采用宽松归一化（大小写、空格/连字符、URL 解码差异都能命中），不出现“跳到错误位置”。
  - 外链（http/https）点击交系统浏览器打开，不在应用内导航。
- HTML：**沙箱化静态预览**——iframe `sandbox`（禁脚本/表单/对象/顶层导航）+ 文档内 CSP；本地图片内联 data URL；外链交系统浏览器
- 安全：Markdown 内嵌 HTML 不渲染；HTML 不执行脚本；无脚本执行
- **>800 万字符文档禁用预览**（防 OOM）并提示
- 分屏布局（编辑+预览）双向滚动定位（Markdown）

### 3.7 设置与主题 ✅
- 编辑器/预览字体字号：Windows 系统字体对话框 + 数字微调；行高、制表宽度、自动换行、行号、布局、自动保存开关与间隔
- 内置浅/深主题；导入 VS Code 主题 JSON（解析 colors+tokenColors 映射，可删除、可多主题共存）
- 状态栏配色使用主题 statusBg（导入主题取自身 statusBar.background，缺失用中性色，不再强制蓝色）
- **界面配色跟随主题**：顶栏、标签条、品牌下拉/二级菜单、最近打开列表、设置/信息/关于/许可证对话框统一取主题的 `--bg/--fg/--border/--accent` 等变量（修复早期深色主题下弹层仍为浅色的问题）
- “保存并退出”= 保存设置并关闭设置页（不退出应用）

### 3.8 大文件处理（L1/L2/L3）✅
- L1：手动打开 >20MB 弹确认（后台打开/取消）；会话恢复跳过 ≥64MB
- L2：确认后的大文件后台打开不抢焦点；超大标签关闭撤销历史；切换时“正在加载大文件…”
- L3：超大（≥4000 万字符）干净标签常驻上限 4 个，超限自动退化为轻量占位，激活时原地重载；预卸载避免峰值瞬态
- 详见 `large-file-strategy.zh.md`

### 3.9 编码与边界 ✅
- UTF-8（含 BOM）读写；BOM 同文件保存保留
- UTF-16/32 打开即提示转存（不静默乱码）
- 其它非 UTF-8：尽力解码显示，原文件原地保存被拒绝（引导另存为），防覆盖损坏

## 4. 非功能需求（当前达成）
| 项 | 目标/实测 |
|---|---|
| 启动速度 | 正常会话 <2s 级；超大文件不自动载入 |
| 大文件编辑 | 10×100MB 顺序打开累计 ~112s、内存平台 ≤~4.7GB（含 L3，详见性能文档） |
| 大文件预览 | >800 万字符禁用，杜绝 OOM |
| 数据安全 | 自动保存仅快照；写文件原子化（临时文件+rename）；快照 key 防路径穿越；快照回读校验 originalPath 与 stem 哈希一致 |
| 可移植 | exe 单文件 + 旁置 settings/autosave；不可写自动回退 |
| 兼容 | Windows 10/11 x64；依赖系统 WebView2 Runtime |
| 合规 | MIT（仓库 LICENSE）；帮助内第三方许可证清单 |
| 安全 | 生产 CSP（`default-src 'self'`，无远程脚本/连接）、无 asset 协议全盘读面、外链仅 http(s) 白名单经系统浏览器、主题颜色与字体串白名单校验、图片读取 40MB 上限、文本 512MB 上限 |
| 响应性 | 文件/快照 IPC 全部异步实现，大文件读写期间 UI 不冻结；快照列表只读头部 2KB 取摘要 |

## 5. 约束与运行环境
- 仅 Windows x64；系统需 WebView2 运行时
- 文件按 UTF-8 语义处理（见 3.9）
- 首次运行未签名提示（SmartScreen），需“仍要运行”
