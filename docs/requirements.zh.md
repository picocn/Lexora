# Lexora 需求文档（Requirements）

- 适用版本：当前实现基线 0.2.2
- 相关文档：`design.zh.md`（设计）、`acceptance.zh.md`（人工验收清单）、`large-file-strategy.zh.md`（大文件性能方案）

## 1. 产品概述
Lexora 是一款轻量级 Markdown 多标签桌面编辑器，面向个人写作/笔记场景，定位“开箱即用、便携绿色、不丢数据”：

- 技术栈：Rust + Tauri 2 + WebView2（Windows x64）+ React 18 + CodeMirror 6
- 核心承诺：
  1. **自动保存绝不写原文件** —— 只写恢复快照；
  2. **退出即安全** —— 退出不再询问，自动为未保存内容补写快照；
  3. **可移植** —— 设置/快照默认放 exe 旁，目录不可写时回退系统用户目录；
  4. **大文件可控** —— 超大文件编辑/预览有护栏与驻留上限，避免卡死与 OOM。

## 2. 目标与非目标
### 目标
- 常用 Markdown（标题/列表/表格/任务列表/代码块/图片/LaTeX/Mermaid）阅读与编辑体验
- 多标签、语法高亮、可中文化的菜单/设置/帮助
- 崩溃与误关不丢未保存内容

### 非目标（本期）
- 不内置云同步/多人协作
- 不做超大型文档的虚拟化渲染（列为远期）
- 不支持非 UTF-8 原文编辑（UTF-16/32 拒绝打开并提示转存；其他编码尽力显示、只允许另存转 UTF-8）

## 3. 功能需求（实现状态标注：✅ 已实现）

### 3.1 窗口与外壳 ✅
- 无原生标题栏，自绘顶栏：图标 + 应用名 + 菜单栏同排（文件/编辑/帮助）
- 拖拽空白区移动窗口、双击最大化/还原；右上角 最小化/最大化/关闭
- 窗口大小/最大化状态持久化，启动恢复后显示（避免闪烁）
- 帮助：使用说明 / 版本说明 / 许可证（MIT 全文 + 主要第三方许可表）/ 关于

### 3.2 标签与多文档 ✅
- 编辑标签与只读预览标签（`xxx-预览`）
- 标签条无滚动条：左侧 ‹ › 循环切换上/下一个标签并自动滚动到可见；最右「＋」新建
- 关闭：菜单/× /Ctrl+W /中键；关闭未保存单个标签需确认（保存 / 不保存并关闭 / 取消）
- 未保存指示（●）、语言显示、最近打开（≤10）

### 3.3 编辑与语法 ✅
- 按扩展名自动语言（md/yml/toml/html/css/js/ts/json/rust/python/java/c/c++/c#/go/sql/sh/ps1/php/rb/xml…），状态栏可手动覆盖
- 撤销/重做（超大文件标签关闭 undo 历史）、剪贴板、全选
- 查找/替换：Ctrl+F 打开面板（查找+替换栏），上一个/下一个/全部替换（执行前确认替换数），区分大小写/正则/整词

### 3.4 自动保存与恢复（核心语义）✅
- 定时（默认 5s，可配置/关闭）把有未保存改动的编辑标签写入**恢复快照**（autosave/），**从不覆盖原文件**
- 手动保存/另存为是写原文件的唯一入口（原子写，防截断；同文件保存保留 UTF-8 BOM）
- 启动：自动恢复遗留快照（提示 5s 自动消失）→ 重开上次会话文件（跳过 ≥64MB 并提示）→ 无标签则新建未命名
- 退出（菜单/关闭按钮）：先存会话，再为所有未保存标签补写最新快照，清理干净标签的过期快照，然后退出——**不弹保存询问**

### 3.5 Markdown 预览 ✅
- 预览入口：标签栏「▶ 预览」/文件菜单/Ctrl+P；预览标签只读实时渲染
- GFM 表格/删除线/任务列表；LaTeX（KaTeX $..$）；Mermaid 流程图；本地图片（含中文/空格路径）经 base64 加载
- 安全：markdown 内嵌 HTML 不渲染；无脚本执行
- **>800 万字符文档禁用预览**（防 OOM）并提示
- 分屏布局（编辑+预览）双向滚动定位

### 3.6 设置与主题 ✅
- 编辑器/预览字体字号：Windows 系统字体对话框 + 数字微调；行高、制表宽度、自动换行、行号、布局、自动保存开关与间隔
- 内置浅/深主题；导入 VS Code 主题 JSON（解析 colors+tokenColors 映射，可删除、可多主题共存）
- 状态栏配色使用主题 statusBg（导入主题取自身 statusBar.background，缺失用中性色，不再强制蓝色）
- “保存并退出”= 保存设置并关闭设置页（不退出应用）

### 3.7 大文件处理（L1/L2/L3）✅
- L1：手动打开 >20MB 弹确认（后台打开/取消）；会话恢复跳过 ≥64MB
- L2：确认后的大文件后台打开不抢焦点；超大标签关闭撤销历史；切换时“正在加载大文件…”
- L3：超大（≥4000 万字符）干净标签常驻上限 4 个，超限自动退化为轻量占位，激活时原地重载；预卸载避免峰值瞬态
- 详见 `large-file-strategy.zh.md`

### 3.8 编码与边界 ✅
- UTF-8（含 BOM）读写；BOM 同文件保存保留
- UTF-16/32 打开即提示转存（不静默乱码）
- 其它非 UTF-8：尽力解码显示，原文件原地保存被拒绝（引导另存为），防覆盖损坏

## 4. 非功能需求（当前达成）
| 项 | 目标/实测 |
|---|---|
| 启动速度 | 正常会话 <2s 级；超大文件不自动载入 |
| 大文件编辑 | 10×100MB 顺序打开累计 ~112s、内存平台 ≤~4.7GB（含 L3，详见性能文档） |
| 大文件预览 | >800 万字符禁用，杜绝 OOM |
| 数据安全 | 自动保存仅快照；写文件原子化（临时文件+rename）；快照 key 防路径穿越 |
| 可移植 | exe 单文件 + 旁置 settings/autosave；不可写自动回退 |
| 兼容 | Windows 10/11 x64；依赖系统 WebView2 Runtime |
| 合规 | MIT（仓库 LICENSE）；帮助内第三方许可证清单 |
| 安全 | 生产 CSP；无 asset 协议全盘读面；图片读取 40MB 上限 |

## 5. 约束与运行环境
- 仅 Windows x64；系统需 WebView2 运行时
- 文件按 UTF-8 语义处理（见 3.8）
- 首次运行未签名提示（SmartScreen），需“仍要运行”

## 6. 验收对照
